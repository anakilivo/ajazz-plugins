# GitHub (`com.anakilivo.streamdock.github`)

Pull request'ы GitHub на клавишах и крутилке Stream Dock. Один архив для macOS и Windows — нативного кода нет.

| Действие | Где | Что показывает / делает |
|---|---|---|
| PR на ревью | клавиша | сколько PR ждут вашего ревью; нажатие — открыть список (или сам PR, если он один) |
| Мои PR | клавиша | ваши открытые PR, полоска внизу — общий статус CI (зелёный / жёлтый / красный) |
| Лента PR (крутилка) | крутилка | поворот листает PR на полосе (репозиторий, номер, название, автор, CI); касание экрана — открыть PR; нажатие крутилки на ленте «на ревью» — «посмотрел» |

**На ревью** — PR, где вас добавили ревьюером, и все открытые PR из репозиториев, указанных в настройках
(кроме ваших). Черновики не показываются. Явно запрошенные идут первыми («вас просят»).
PR пропадает из списка, если вы нажали «посмотрел» на крутилке или уже оставили ревью
(approve / comment / request changes) на последний коммит, и возвращается, когда автор пушит новые коммиты.

**Мои PR** — ваши открытые PR в тех же репозиториях (если список пуст — по всему GitHub).

Репозитории, токен и скрытые PR хранятся в глобальных настройках плагина и общие для всех действий.
Данные обновляются раз в минуту одним GraphQL-запросом и после нажатия на клавишу.
Пока на устройстве нет ни одного действия плагина, запросов нет.

Нажатие крутилки и касание экрана над ней Stream Dock присылает одним событием `dialDown`;
плагин различает их по сопутствующим событиям (см. `createPressClassifier` в `actions/common.js`).

## Вход

1. Если установлен [GitHub CLI](https://cli.github.com) и выполнен `gh auth login` — ничего делать не нужно,
   токен берётся из `gh auth token`.
2. Иначе — вставьте Personal Access Token в настройках любого действия плагина
   (classic: scope `repo`; fine-grained: Pull requests — read). Токен хранится в настройках Stream Dock
   и имеет приоритет над `gh`.

## Устройство

```
com.anakilivo.streamdock.github.sdPlugin/
  manifest.json
  plugin/
    index.js         точка входа
    sdk.js           WebSocket-протокол Stream Dock, логи в log/
    github.js        вход (токен / gh), GraphQL-запрос, опрос
    render.js        SVG клавиш (144×144) и полосы (176×112), Octicons
    raster.js        SVG → PNG через resvg (WebAssembly)
    actions/         counter.js — клавиши, feed.js — крутилка
  pi/settings.html   настройки: вход, токен, список для ленты
scripts/build.sh     npm, иконки, dist/…zip; --install — симлинк в Stream Dock (macOS)
scripts/icons.js     иконки для manifest.json
```
