# Яндекс Музыка (`com.anakilivo.streamdock.yamusic`)

Плеер десктопной Яндекс Музыки на Stream Dock: обложка, трек и волна под музыку на полосе
над крутилкой, клавиши управления с текущим состоянием.

| Действие | Где | Что показывает / делает |
|---|---|---|
| Сейчас играет | крутилка | обложка, трек, артист, волна, прогресс и время; поворот — перемотка, нажатие — пауза/играть, касание экрана — лайк |
| Обложка | клавиша | обложка с полосой прогресса, на паузе — затемнение; нажатие — пауза/играть |
| Пауза / играть, следующий, предыдущий | клавиши | — |
| Лайк, дизлайк | клавиши | состояние лайка текущего трека |
| Вперемешку, повтор | клавиши | текущий режим (выкл → список → один трек) |

В настройках крутилки: вид волны (эквалайзер, зеркальная волна, светящаяся линия, без волны),
цвета (из обложки или свой), текст (трек и артист, только трек, без текста), шаг перемотки.

## Как это работает

- **Управление.** Плагин подключается к странице Музыки через отладочный порт
  (`--remote-debugging-port`, по умолчанию 9222) и ставит на неё небольшой скрипт
  (`plugin/page.js`). Данные трека он берёт из Media Session (то же, что Музыка отдаёт
  системе), позицию, лайки и режимы — из плеера по `data-test-id`, а не по CSS-классам.
  Если Музыка закрыта или запущена без порта, нажатие на любое действие запускает её с портом
  (запущенную без порта — закрывает и открывает заново).
- **Волна.** Помощник `bin/spectrum-helper-mac` (Swift, `native/mac`) перехватывает звук
  только Яндекс Музыки через Core Audio Process Tap (macOS 14.2+), не приглушая его, раскладывает
  на 24 частотные полосы и ~30 раз в секунду отдаёт их плагину. Полоса над крутилкой
  перерисовывается 20 раз в секунду, пока играет музыка (больше устройство не показывает).
  При первом запуске macOS спросит разрешение на запись звука для «Yandex Music Dock».
- На Windows волну даёт `bin/spectrum-helper-win.exe` (C++, `native/win`): WASAPI process loopback
  захватывает звук только Яндекс Музыки (Windows 10 сборки 20348+ и Windows 11). На более старых
  Windows помощник берёт весь звук устройства вывода — волна тогда реагирует на любой звук.

## Сборка

```
scripts/build-mac.sh [--install]   помощник (universal), npm, иконки, dist/…-macos.zip;
                                   --install — симлинк в Stream Dock и перезапуск
scripts/build-win.sh               помощник для Windows (zig), dist/…-windows.zip (после build-mac.sh)
```

## Устройство

```
com.anakilivo.streamdock.yamusic.sdPlugin/
  manifest.json
  plugin/
    index.js         точка входа
    sdk.js           WebSocket-протокол Stream Dock, логи в log/
    cdp.js           клиент Chrome DevTools Protocol
    page.js          скрипт на странице Музыки: состояние и команды
    music.js         подключение, состояние плеера, команды
    launcher.js      запуск Музыки с отладочным портом
    spectrum.js      помощник волны и сглаживание уровней
    cover.js         обложка и цвета из неё
    render.js        SVG клавиш (144×144) и полосы (176×112)
    raster.js        SVG → PNG через resvg (WebAssembly)
    actions/         nowplaying.js — крутилка, keys.js — клавиши
  pi/settings.html   настройки
native/mac/          помощник волны для macOS (Swift)
native/win/          помощник волны для Windows (C++)
scripts/             сборка, иконки
```
